# DuggansDingers V26 Premium Matchups

## Connection status
Settings now determines connection status from data actually loaded and configured
secret names. It distinguishes connected, configured, waiting, live fallback, and
prepared-snapshot states without exposing secret values.

## Matchup Center
Dropdown expanders were replaced with premium clickable matchup thumbnails.
Each full matchup page includes both starters, pitcher hand, ERA, WHIP, HR/9,
K/9, hard-hit rate, batter Dinger Score, HR probability, barrel rate, hard-hit
rate, matchup score, platoon edge, weather, and sportsbook price.

## Weather
The old vector-field/logo-watermark backgrounds were replaced by a photo-only
30-team prototype-style stadium pack. Team logos use illuminated plates and
strict venue/team mapping.
