# DuggansDingers V16

A dark-neon MLB home-run intelligence dashboard built with Streamlit.

This release uses the supplied template as the homepage design direction while preserving player photos in the six featured picks. It adds a glowing sidebar, faster page-specific loading, repaired stadium/probable-pitcher matching, three-column weather cards with detail pages, side-by-side team sheets, and AI-style game simulation reads.

See `DEPLOY_STREAMLIT.md` for the update process and `V16_FEATURES.md` for the full change list.
