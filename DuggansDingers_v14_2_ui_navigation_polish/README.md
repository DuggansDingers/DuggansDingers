# DuggansDingers V17

A Streamlit MLB home-run intelligence dashboard with Ballpark Pal projections, MLB player and probable-pitcher data, Statcast signals, multi-provider weather, sportsbook prices, team sheets, game simulations, and a lockable parlay builder.
